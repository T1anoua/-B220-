# -B220-
本项目面向高速输送带矿石智能分选场景，设计一套基于FPGA的动态矿石空间姿态估计与跟踪系统。针对矿石形貌不规则、随机堆叠、局部遮挡以及高速运动条件下目标姿态变化快、跟踪易丢失等问题，系统融合视觉检测、三维几何重建、空间姿态估计与动态跟踪技术，利用对称性先验增强缺失点云的几何恢复能力，并结合SO(3)旋转等变特征实现矿石六自由度空间姿态的稳定估计。 在此基础上，结合多目标时序关联与运动状态预测，实现矿石位置、姿态、速度及运动轨迹的连续输出，并利用FPGA并行计算优势提升视觉处理实时性，为后续机械臂动态抓取和矿石智能分拣提供高速、稳定的感知信息。基于AMD ZYNQ7020 b
